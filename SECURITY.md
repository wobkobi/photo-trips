# Security policy

## Supported versions

Only the latest release of Pic Cabinet gets security fixes. Installed copies check for updates
daily and offer new versions in Settings > About, so the fix for a problem is to update.

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Email
harrison@tothepoint.co.nz with:

- what the problem is and what someone could do with it
- the version affected (Settings > About)
- steps to reproduce it, or a proof of concept

We'll reply within 5 working days, keep you updated while we work on a fix, and credit you in the
release notes if you'd like.

Things we especially want to hear about:

- anything that could get an update installed that wasn't signed by us
- any way the app could change, delete or expose files outside the folders you gave it
- anything the app sends over the network that [PRIVACY.md](PRIVACY.md) doesn't describe
